# 常见问题

## 安装后找不到 Skill

打开新对话，再明确说「使用 tennisprism」。Codex 可输入 `$tennisprism`，Claude Code 可输入 `/tennisprism`。确认安装的是完整文件夹，且 `SKILL.md` 位于该文件夹的第一层。已有同名安装时先核对路径，避免多个副本同时被发现。

## 我已经把视频拖进聊天，为什么还要文件路径

某些宿主会展示附件，却不给 Agent 可读取的原文件。只有宿主实际能读取视频时才能处理。可以改用本地绝对路径，或使用视频选择页。不需要把私人视频传到公开仓库。

## 网页停在旧版「等待当前 Agent 接续」

这是 1.0.0 的交互缺口：打开页面后 Agent 可以结束回复，上传只整理证据，必须再发聊天指令才能分析。1.0.1 改为 Agent 持续等待并自动接收，结果显示在网页；H5 按钮也由本机服务直接执行。

更新完整 Skill，并重启使用同一 workspace 的本机服务，让 Agent 重新读取新版并进入等待。不必删除或重复上传已有视频。更新文件不会自动更新旧进程。

## 新版显示「正在等待分析端连接」或「连接已中断」

页面会检查 Agent 最近是否实际调用等待/处理命令，浏览器自身的轮询不能伪造在线状态。就绪前无法上传或开始新分析，已经提交的任务会保留。

需要宿主在当前任务中连续调用 `coach.py wait`，而不是打开链接后就发出最终回复；一次 25 秒等待超时并不代表整个任务完成。处理时需按 Skill 的约定续期。如果宿主强制结束执行，普通 Skill 无法从网页唤醒已结束的聊天。可以重新启用 Skill 处理保留任务，或使用直接附件流程；不能声称未验收的宿主一定支持网页闭环。

千问办公的官方文档确认可以安装完整 Skill；这不是对 TennisPrism 网页接续的端到端保证。当前修复已在 Codex 实际验证，千问办公仍待实测。无需另填模型 API Key，也不提取账号令牌。

## 点击「生成完整视频复盘」失败

1.0.1 在本机直接生成，不需要重新唤醒模型。错误原因会显示在按钮附近，可重试；已有文字报告保留。没有经过复核的姿态数据时生成无骨架版本。若服务中途重启，重启后可再次点击生成。

## 网页打不开

先让 Agent 重新启动同一任务目录的本地服务，并使用这次输出的地址。端口可能变化；链接只有服务运行时有效。

如果 Agent 在远程容器/服务器上，`127.0.0.1` 指向远程机器，需要宿主支持的端口转发或其他可用的文件通道。不要直接把本地原型暴露到公网。

## 提示缺少 Python 依赖

让 Agent 运行 Skill 自带的 `scripts/coach.py doctor`，再在任务虚拟环境中安装 `scripts/requirements.txt`。推荐 Python 3.12。首次安装需要能访问正规软件包源；没有安装成功时不要跳过错误继续生成旧报告。

## 没有骨架或跟随放大

初步分析本来就不要求姿态模型。完整 H5 的骨架依赖单独的 MediaPipe 环境、官方模型权重和对人物范围的复核；具体流程在 Skill 的 `references/h5.md`。

身体太小、遮挡、模糊、模型安装失败或跟错人时，可以保留无骨架版本。不会用画出来的骨架替代真实推理。长视频仅在所引用证据附近计算姿态。

## 评级前后差半级

短片估计有主观性，目前没有校准到可复现的官方评级。检查证据是否相同、置信度、是否包含连续回球结果等。不要用一次低置信度分数判断训练进退；建议用相同拍摄条件和练习任务记录变化。

## 怎样反馈更有帮助

在 GitHub Issues 里注明系统、Python/Agent 版本、用法一还是用法二、出错步骤、预期结果和脱敏日志。可以给动作时间点。不要贴 API Key、账号令牌、私人绝对路径或未经同意的他人视频；只有愿意公开且有权分享时再附素材。
