# 从观察到训练

目标是说明这个人在哪类来球下需要什么练习。每份报告可有 0–3 项建议，不要求填满。先识别已有能力，再决定哪些需要改善或验证；不凭缺失的发球、网前片段降低所有项目评分。骨架辅助回看，不直接决定训练或等级。

## 从片段中选出个人问题

1. **核对动作阶段。** 连看准备前、击球与击后过程，确认目标、持拍手、击球类型和来/出球方向。球员刚打完球、球还在飞向对面时，低拍或调整脚步不等于下一拍准备晚。球拍在身体后方也可能是随挥。方向不清就补看上下文；仍不清的帧不能支撑确定的时机诊断。
2. **按来球场景归组。** 同一人、同一击球类型，还要考虑来球高度/深浅、移动方向、攻守处境和可见节奏。看不清的条件写未知。不能拿向前迎球的正手与被拉出场地的正手，直接判成好动作与坏动作。不同场景只能作背景对照。
3. **找重复表现，也找反例。** 检查多个独立击球，而非把同一拍的多个帧当重复发生。选择一段同条件下较从容的击球作为对照；没有可比样本就承认缺失，不能杜撰成功片段。报告中的内部证据核对不等于启动用户可选的独立动作对比模式。
4. **核对实际影响。** 观察是否挤住/够球、回球是否变差、下一拍是否仓促；区分动作现象和影响。较大的最后一步、起跳、后退或开放站位本身都不构成错误。球落点或下一拍不可见，就不能补写出界、回浅或回位慢。
5. **选择最少的干预。** 先分清判断/启动、移动与间距、击球组织、线路选择分别是否有依据，不把所有问题归因于手臂发力。保留已有效的动作。单机位投影、模糊程度和骨架不能证明动力链、地面反力、力量病因或固定“理想角度”。

若两个球员得到同一种练习，必须能分别解释各自的场景、证据与验收标准。不要为了显得不同而编造不同缺陷；更具体的组数和更长的文案不等于更有针对性。

## 发现类型

- observed：连续画面直接支持观察。只有动作阶段明确、多个独立同类击球反复出现、可见影响也有依据时，才能用 selection.role=focus 列为本次重点；否则用 trial 检验，不把直接看见某姿态等同于确认缺陷。
- potential：现象有依据，原因或影响尚未确定。selection.role=trial，给替代解释及低风险试练，不先宣布有缺陷再强改动作。仍可提供有价值的行动建议。
- development：巩固或拓展已有能力，selection.role=optional。只有与用户目标或已观察能力有关才选；缺失落点测量不是他需要加强控球的证据。不要用它填满个人重点。

置信度为定性 low/medium/high，不是成功概率。判断不确定不等于练习没价值；练习的价值可以是帮助验证假设。没有足够依据选练习时允许不提供，不编造伤病、力量不足或握拍问题。

## 每项训练要回答

1. 为什么是这个人、这类来球、现在值得练：真实时序、重复性、可比片段/反例、可见影响；哪些有效动作继续保留。
2. 怎么摆、怎么练：人数、场地/目标、节奏、具体步骤和可调整的量。
3. 本次只检验什么：一个可执行的调整变量和一句口令。不要同时要求提前转身、增加碎步、改变站姿、加大转体，再把改善归于其中某一个。仅建立基线时写清保持原动作、只记录表现。
4. 记录什么：可重复的回球目标计数、连续动作或相同观察窗口；不要从未测出的原片生成基线数字。
5. 什么结果支持继续练：同样条件下更从容/回球质量不降/下一拍准备改善。
6. 什么结果应否定或修改建议：旧动作一样好、来球条件不同、改法让质量下降。对照几球只给线索，不证明唯一因果。
7. 太难或太易怎么改：一次改变一个条件，不从慢速试练直接跳到极限动作。

条件合适时从 [训练参考与选择条件](practice-library.md) 取方法，再按本人证据设计。参考资料提供候选，不自动证明适合这个人。已有连续表现不支持问题时，可不选纠正练习；有局部线索但影响未知时，可选基线/验证练习。

## 有历史资料时

仅使用用户明确关联为同一人的报告与视频。近端、衣服相似、同一 workspace 都不是同人证明；没有历史也可完整分析，不例行追问。当前 Skill 没有自动身份识别或跨会话档案检索。

先读上次训练目标、练习条件和真实记录，再复看相关证据。区分同一素材的报告修订与不同日期的训练；重写报告不是训练进步。来球条件或机位不可比时不能写改善/退步。旧报告文字只提示要复查什么，不是本次新证据。历史帧不塞入当前 manifest 的引用；注明其独立来源与未复核处。

若旧问题已不再出现，说明本次不继续主推该练习；仍出现则检查是否真正练过、条件是否可比，不能只重复上一份建议。源头为 [AISportCoach 的历史报告检索设计](https://github.com/LeonLdv/AISportCoach)，本项目只借鉴连续复核方法，没有接入其云模型、向量库或复制代码。

## 方法来源与边界

[Tennis Clip Coach](https://github.com/ZhenglunZhong/tennis-clip-coach) 的诊断/动作分类参考提示了先分类、核对来出球与阶段、同人片段对照的价值。这里独立编写流程，没有复制或运行其代码；它的因果判断与简化规则不作为已验证标准。尤其不能按“触球后落地的分腿垫步必然晚”或“转肩转髋同步必然错误”机械判断。本次查阅日期 2026-11-11。

格式校验能拒绝缺失依据和错误引用，不能验证场景是否可比、是否确实重复、训练是否有效；这些仍需实际看图和后续练习反馈。

## 原创验证练习示例：高反手让位

前提是连续画面显示近端反手后撤、高位挥拍与击后继续后移。可以提出“前后站位调整是否偏晚”，但高深球本来就可能需要后撤，起跳本身不等于错误。

在相近高度、深度、速度的喂球下，先记录平时的处理。只有重复表现支持“让位开始偏晚”时，再用 A（原动作）与 B（仅尝试更早启动后撤让位）交替比较，保持挥拍方式、目标区和节奏不变。不要同时改变侧身方式或强抢上升点。可各记录 8 球，交换顺序再看；明显不同的喂球单列。允许必要起跳。比较回球与下一拍准备；无稳定优势就保留原动作。

这是原创验证示例，数量不是科学阈值；不确认唯一因果，不给每个用户套用。
