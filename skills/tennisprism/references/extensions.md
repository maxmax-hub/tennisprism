# 额外视频与落点请求

核心 Skill 提供教练复盘与 H5，不自动进行整场回合剪辑、商业付费摄像服务或成片渲染。用户明确要求时可以扩展，但按本次实际输入、工具与授权实现。

过去样例曾尝试球轨迹、落点与视频叠加。这些实验不是本 Skill 的已验证通用能力：

- 单帧或单目固定镜头看不见的落点，可以在明确允许推测时给条件性估计及定性置信度；必须标记推断、假设和遮挡。无标定不能冒充真实球场米制坐标或落点判罚。
- 区分可见球位置、实际模型候选、人工校正、插值和预测。真实落地应有连续下落/反弹证据；热图分数不是落点正确概率。
- WASB-SBDT、TrackNet 类项目偏向球检测/轨迹，MediaPipe 偏向人体姿态。工具输出并不证明训练建议有效，也不自动解决相机标定、身份跟踪和遮挡。
- 如确需引入新的开源模块，先核对当前官方仓库、许可证、依赖和权重，再在独立环境运行；保留原始结果、模型版本、覆盖窗口及可复现输出。不复制许可证不明的教练代码，不把 LLM 生成的理想角度当专业标准。

用户只要本次分析或 H5 时，不额外下载大型追踪项目，不制作未要求的视频画幅，也不把早先私人视频或模型输出打进公开包。
