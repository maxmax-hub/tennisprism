# 可选 H5、真实骨架与跟随放大

用户要完整复盘页后，使用已验证报告生成 H5。默认优先尝试真实姿态；依赖或模型不可用时仍能生成无骨架版本，并说明原因。普通初步分析不需要先跑姿态。

## 姿态模型

官方资料：[MediaPipe Python 指南](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/python)、[模型下载](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/index#models)。使用官方 Full 模型下载链接，存入工作目录的模型缓存；不要复制私人安装路径或把权重塞进技能包。首次下载/安装遵守宿主授权规则。优先复用已存在的可核对模型。

可选环境依赖在 `scripts/requirements-pose.txt`；本轮可用基准为 Python 3.12 + MediaPipe 0.10.21。使用独立环境避免影响基础服务环境。脚本依赖包必须真实可用，不能把未执行写成已执行。

1. 从原片概览与多个时间点确认目标人物，选一个覆盖活动范围、尽量排除另一人的矩形。ROI 用 0..1 的左、上、右、下坐标；不要用所有视频通用的硬编码矩形。
2. `python <skill>/scripts/pose.py infer --workspace <workspace> --run <run-id> --model <model.task> --roi 0.1 0.3 0.9 0.98`。坐标只是语法示例，执行前用实际画面确定。
3. 打开输出的 review.jpg，核对身份、身体节点、遮挡与裁切。在明显异常或不确定时补查对应原帧；不能把检测数量当准确率。
4. 满意后执行 `pose.py approve --workspace ... --run ... --candidate <pose.json>`；否则不 approve，交付无骨架版本并说明问题。approve 记录人工视觉复核，不证明正确率。
5. `coach.py h5 --workspace ... --run ...`。模型结果必须与当前预览哈希和目标匹配，且已复核。新 H5 版本包含视频，因此默认仅供用户本地查看，不公开上传。

visibility 与 presence 都达到 0.65 才显示节点，不补画缺失骨架。不用二维骨架估计医学风险、精确关节角或标准挥拍分数。局部放大根据实际通过过滤的人体位置跟随；没有可靠位置时显示缺失，不悄悄追另一个人。

120 秒以内运行完整预览骨架；更长视频仅在报告引用证据的前后 2 秒窗口推理，其他时间骨架为空。视频预览逐帧时间来自实际解码，源视频可能是高帧率，页面明确标为“预览帧”。它不是每一拍完整诊断。

## 页面验收

实际打开本机 URL，检查视频播放、证据跳转、至少一次下一帧、慢放、骨架与跟随开关、潜在问题练习的验证标准。没有浏览器工具时检查输出资源并如实说明未做视觉验收。服务关闭后本机 URL 失效，需要重新启动同 workspace；不要承诺永久链接。
