# 首版等级约定

每份有效的 3.0 报告必须给出一个 **NTRP 尺度的视频估计等级**，并单独显示低/中/高置信度、可见依据和未观察项目。采用半级档位，不使用自定义百分制，不把“证据不足”作为最终等级。

模型参考 USTA 的公开分级描述，选择最符合可见表现的等级；部分能力没拍到时仍给暂定值，把不确定性放进置信度和依据。没有拍到发球，不等于发球水平低；没有连续球轨迹，不得虚构回球成功率或落点。

## 参考与身份

- [USTA General Characteristics](https://www.usta.com/content/dam/usta/sections/eastern/pdfs/NTRP%20Characteristics.pdf)：一般特征表包含 1.0–7.0，半级递增。本应用按此表取值，不给 3.27 等伪精确等级。
- [USTA NTRP FAQ](https://www.usta.com/en/home/play/adult-tennis/programs/national/usta-ntrp-ratings-faqs.html)：官方评级涉及 USTA 流程及比赛记录；第三方视频估计不是 USTA 官方评级，不自动取得报名资格。
- [UTR 计算说明](https://support.universaltennis.com/en/support/solutions/articles/9000151894-how-is-the-utr-rating-calculated-)：评级依赖对手水平、比赛局数结果及时间权重。当前仅有视频，首版以 NTRP 为主，不由它换算或伪造 UTR。

这是一项依据官方量表描述的主观视频估计，没有经过教练标注集校准。界面、导出和结构化数据均保留 video_estimate 身份。没有申请、读取或改动任何官方评级。

## 本地判断锚点

以下为 USTA General Characteristics 的简要转述，便于离线读说明；它不代替完整量表和比赛记录。比较相邻两档与实际可见表现，不靠动作好看或单次回球决定等级：

| 档位 | 主要区别 |
|---|---|
| 1.0–1.5 | 刚开始或经验有限，主要练习把球打入场。 |
| 2.0 | 仍在建立击球点与基本站位。 |
| 2.5 | 可在慢节奏下与相近水平球员持续对拉，移动和回位尚不高效。 |
| 3.0 | 中速球有一定稳定性，控制方向、深度和变化仍有限。 |
| 3.5 | 中速击球有可靠性和方向控制，深度、变化和部分专项仍不足。 |
| 4.0 | 正反手能控制方向及深度，也能运用多种击球。 |
| 4.5 | 能主动变化速度、旋转和战术，发球与场地覆盖更有效。 |
| 5.0–5.5 | 有明显武器，可主动终结短球，竞争压力下保持策略与稳定性。 |
| 6.0–7.0 | 涉及高级别比赛训练与排名背景，不能仅凭短片姿态确认。 |

不能只因一次高球处理困难把人定在 3.0；也不能把未看到的方向控制默认算作已掌握。短片下给暂定估计，依据中说明最接近的可见特征及缺口。来源为上面的 USTA 特征表。

## 证据置信度

置信度描述证据充分程度，不是校准后的正确概率：

- 低：短片、模糊、遮挡，或只覆盖少量动作。仍给暂定等级，但更多录像可能改变它。
- 中：多次清晰动作及相关上下文支撑同一判断，仍有关键项目未覆盖。
- 高：较充分、清晰且一致的表现支持判断；本首版稀疏采样谨慎使用。

完全无法识别目标或动作的文件不能虚构等级，应作为输入或分析失败处理。它不同于“部分能力没拍到”。

## 用户表达

报告首先回答「现在什么水平」「最值得改善什么」「下一次怎么练」。给出有依据的教练判断与推测，使用直接、具体的中文。置信度独立显示，不在每条结论后反复追加「可能」「无法确认」「证据不足」。缺失能力与抽样范围集中放进可展开的说明；详细依据保留供用户核查，不让帧编号和分析过程占据正文。清楚的表达不代表将推测改写成已测量的事实。

## 校验

评级必须匹配本次证据身份、半级间隔与摘要；具体契约见 report.md。校验失败时根据真实证据修正，不能根据程序偏好替换模型分数。历史报告保持原样，不追填新等级。
