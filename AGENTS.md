# TennisPrism

Read README.md for the two user workflows and docs/development.md for the runtime and validation contract. Skill instructions live in skills/tennisprism/SKILL.md.

- Preserve original videos. Keep user media, reports, credentials, models and runtime environments out of version control.
- Distinguish direct observations from inferences. Cite actual frame IDs and timestamps; never invent model runs, diagnoses, ratings or measured performance.
- Default to the nearest player; only change targets when the user requests it.
- Keep host Agent inference separate from local preparation. Disclose the evidence destination; local media preparation does not mean offline AI inference.
- Provide actionable, evidence-linked training. Potential issues can have trial drills, alternative explanations and criteria for supporting or rejecting a change.
- No automatic deletion of local runtime data. Follow the user's host rules for cleanup; retain previous reports and release artifacts.
- Run focused tests for actual changes and real media/browser checks when the affected behavior needs them. Do not claim other hosts or coaching accuracy are verified without evidence.
